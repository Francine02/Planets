Bem-vindo ao projeto de Realidade Aumentada desenvolvido para a disciplina eletiva da Uninter! 

Este projeto utiliza QR Codes como marcadores e um banco de dados da Vuforia para exibir modelos 3D dos planetas do Sistema Solar, juntamente com informações como nome, temperatura, luas e distância do Sol.

## 🎥 Demonstração em Vídeo

Para visualizar o funcionamento do projeto: [clique aqui](https://youtu.be/wUL7J0meG44?si=jROiFaDM2BjCvQl3)

## 🚀 Tecnologias Utilizadas
+ Vuforia Engine 📷
+ Modelos 3D dos planetas 🌌

## 🔍 Como Funciona?

1. Aponte a câmera do dispositivo para um QR Code correspondente a um planeta.

2. O sistema reconhece o código e exibe o modelo 3D do planeta.

3. Informações como título e distância do Sol são exibidas na interface.
   
4. Explore os diferentes planetas disponíveis! 

### Obs.: O projeto inclui todos os planetas do Sistema Solar, exceto o Sol. ☀
